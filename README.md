# CCNewTools

测试大纲 → 测试说明 / 测试记录 转换工具。

从一份第三方测试大纲（.docx）中解析测试项表格，自动生成**测试说明**和**测试记录**两份 Word 文档。

## 特性

- **完全离线** —— 无任何网络请求，适合内网 / 涉密环境
- **跨平台** —— Windows / Linux x64 / Linux ARM64（含银河麒麟 V10）
- **单文件分发** —— 双击即用，目标机器不需要装 Python / Node / Office
- **界面美观** —— 浏览器打开，Vue 3 + Vuetify
