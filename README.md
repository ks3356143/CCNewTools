# 测试文档生成工具（CCNewTools）

把第三方软件测评大纲（.docx）自动转换成《测试说明》和《测试记录》两份 Word 文档。

上百个测试用例、几百条步骤从大纲往两份文档里誊写，费时且容易抄错——这个工具把誊写全部交给机器，人只负责核对与修正。

## 下载

不需要安装任何运行环境（不用装 Python、Node、Office），从 [Releases 页面](https://github.com/ks3356143/CCNewTools/releases) 下载对应系统的单个文件即可：

| 文件 | 适用系统 |
|------|----------|
| `CCNewTools_v1.3.0_win-x64.exe` | Windows 10/11（64 位） |
| `CCNewTools_v1.3.0_linux-x64` | Linux（64 位）；下载后先加执行权限 `chmod +x 文件名`，再在终端运行 |
| `CCNewTools_v1.3.0_kylin-v10` | 银河麒麟 V10（与 Linux 版相同文件，暂未实机验证） |

## 使用方法

1. **启动**：双击 exe（Linux 在终端里运行）。会出现一个控制台窗口，显示访问地址（例如 `http://127.0.0.1:8300`），随后**自动打开默认浏览器**进入工具界面。
2. **打开界面**：个别机器没设置默认浏览器时不会自动弹出，把控制台窗口里显示的地址抄进浏览器地址栏即可。不希望自动打开浏览器的话，加参数 `--no-open` 运行。
3. **三步出文档**：
   - **上传大纲**：把 .docx 大纲拖进上传区或点选上传，工具自动解析出测试项、用例、步骤、通过准则与追踪关系；
   - **核对编辑**：左侧目录树按大纲层级导航，右侧表格单击即改；自动切分拿不准的地方会红色标记，点击徽章可逐个跳转确认；
   - **生成下载**：填好软件配置项名称、测试人员、监测人员等参数，点「生成文档」，浏览器直接下载《测试说明》和《测试记录》两份 Word 文档。

4. **退出**：直接关闭控制台窗口。核对时的修改已自动保存，下次打开自动恢复。

## 主要功能

| 功能 | 说明 |
|------|------|
| 大纲解析 | 自动识别大纲中的测试项表格，提取用例、步骤、通过准则、追踪关系，还原 Word 自动编号的章节号 |
| 问题提示 | 解析发现的问题分级列出；大纲格式有问题时支持手动增删步骤、排除个别用例兜底 |
| 核对编辑 | 目录树导航 + 表格单击即改；切分可疑处红色标记，徽章点击循环跳转定位 |
| 自动保存 | 修改实时保存、重开自动恢复；手动增删的步骤不会丢 |
| 项目管理 | 一份大纲一个本地项目：最近列表直接重开（免重新上传）、两段式删除防误删 |
| 全局参数 | 软件配置项名称、测试人员、监测人员等一处填写、两份文档共用 |
| 文档生成 | 产出《测试说明》（含用例清单、需求追踪表）与《测试记录》，排除的用例不生成 |
| 界面 | 浅色/深色主题切换、目录树搜索、深浅色界面自适应 |

## 数据保存在哪里

全部在 exe 旁边的 `数据/` 文件夹里（上传的大纲副本、核对时的修改、参数与主题设置），不经过任何网络。启动时的控制台窗口会显示数据目录的实际位置；exe 旁边不可写时会改存到 `C:\Users\<用户名>\CCNewTools\` 并在控制台提示。

**换电脑**：把 exe 和 `数据/` 文件夹一起拷贝到新机器即可，历史项目和修改都在。

## 常见问题

**双击后只有一个黑窗口，没见着界面？**
通常浏览器会自动弹出；个别机器没设置默认浏览器时不会弹，把黑窗口里打印的地址（如 `http://127.0.0.1:8300`）抄进浏览器地址栏即可。

**控制台显示的端口不是 8300？**
默认端口被占用时会自动换下一个（8301、8302……），以控制台显示的实际地址为准。

**杀毒软件报警？**
本工具是单文件离线程序，无数字签名时可能被误报，加入信任/白名单即可。

**下载的 exe 首次运行被蓝色提示拦下？**
Windows 对无数字签名程序的常规提示（SmartScreen）：点「更多信息」→「仍要运行」即可。

**在压缩包里直接双击 exe 运行，行吗？**
能运行，但 Windows 会把 exe 解到临时目录里，你的数据也会跟着存在临时目录，电脑清理后数据全部消失。请先把 exe 解压（或移动）到普通文件夹再运行；工具检测到这种情况会在启动窗口提示。

**上传时提示文件被占用？**
先关闭 Word 中打开的同名大纲文档，再重新上传。

**直接关掉窗口，我核对时的修改会丢吗？**
不会。修改在核对过程中已实时自动保存，下次启动打开同一项目即恢复。

**会联网吗？内网能用吗？**
全程零网络请求，专为内网环境设计。服务只监听本机（127.0.0.1），同一网段的其他电脑访问不到你的数据和上传的大纲。

**页面打开是一片空白？**
浏览器版本太旧（需要 2022 年以后的 Chrome / Edge / Firefox）。内网机器浏览器被统一管理时常见，换新版 Edge 或 Chrome 再试。

**公司代理环境下打不开页面？**
浏览器代理设置需要「绕过本地地址」：在代理例外/白名单里加上 `127.0.0.1`，或勾选"对于本地地址不使用代理服务器"。

**生成的文档在哪里？**
浏览器直接下载（默认在「下载」文件夹），工具本身不另存副本。
