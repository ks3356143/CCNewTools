# 11 工具集首页

> 状态：**已确认**（2026-10-10，用户拍板三项决议后定稿；2026-10-12 首屏华丽化修订）
> 来源：新增"追踪文档生成"工具（[12-追踪文档工具](12-追踪文档工具.md)）后，应用从单工具升级为工具集，需要统一入口

## 定位判读（设计技能结论）

应用 ui-ux-pro-max + design-taste-frontend 两项设计技能的结论：

- **这不是营销落地页，是内部工具的工具选择页**——受众是内网非技术同事，trust-first（可信、不花哨、一眼看懂）优先
- **Redesign-Preserve 模式**：品牌资产（#2D5B91 钢蓝、MD3、渐变顶栏、系统字体栈）全部保留，只演进信息架构
- 检索推荐的"Hero + Features + CTA 营销模式"与"Fira 字体外链"**被否决**——产品页非营销页 + 离线硬约束

## 信息架构

```
首页（screen = 0）
 ├─ 工具一 · 大纲转换（screen 1~3，现有三屏不动）
 └─ 工具二 · 追踪文档生成（screen 1~2，见 12 号设计）
```

- **进入逻辑**：首页卡片点击 → `store.tool` 置为对应工具 + 进入该工具第 1 屏
- **返回逻辑**：工具内顶栏「‹ 工具集」→ 回首页；**解析过的状态保留**（回来再进不丢已上传大纲，重新进入工具 1 时仍在原屏）
- 工具一屏号语义不变（1/2/3），工具二独立屏号；首页固定 screen 0

## 首屏华丽化（2026-10-12 用户拍板"首页第一眼有点空，要炫酷华丽"）

设计判读（design-taste-frontend 技能）：**Redesign-Preserve**——品牌资产（#2D5B91、MD3、系统字体栈、离线约束）全保留，把工具选择页升级为"蓝调鎏光"氛围首屏。原"无 hero、无装饰渐变"两条红线由用户本轮拍板推翻，其余红线继续有效。

### 方案构成（全部纯 CSS + 主题 token，离线零外链）

| 层 | 内容 | 实现要点 |
|----|------|----------|
| 环境层 | 三枚主色系光晕（左上/右上/底部）+ 点阵网格 | 径向渐变自带柔边，**不用 blur 滤镜**省 GPU；26~38s transform 漂移动画；点阵 radial-gradient 1px 网点 + 径向 mask 边缘淡出 |
| 标题 | 34px 渐变墨水字 + 7s 缓慢流光 | `background-clip: text` 带 -webkit- 前缀并以 `@supports` 兜底（不支持时回实色主蓝，**防透明字隐形**）；深色主题换浅色渐变保对比 |
| 卡片 | **跟随光标的聚光边框**（spotlight border） | mousemove 把光标写进 `--mx/--my` CSS 变量（直改 style 零重渲染）；渐变环画在 `::before` inset:-1px，**实体底色移到 .inner**——卡片背景透明，inner 盖住环中部只露边缘一圈；**不用 mask-composite**（内网 Chromium 100 不支持） |
| 卡片 | 角落水印大图标（110px 低透明度） | hover 微缩放旋转；同 MDI 图标零新增资源 |
| 卡片 | hover 升起 4px + 阴影加深 + 图标微动 + 顶缘渐变染蓝 | 延续轮 21 hover 语言 |
| 编排 | 标题→副题→卡片（stagger 130ms）→页脚 | cubic-bezier(0.16,1,0.3,1) 进场 |

### 全屏推广（2026-10-12 同日）

用户验收首屏后拍板推广到全部工具屏：共享样式抽到 `web/src/ambient.css`（全局导入，`.amb-wrap`/`.amb-*` 光晕点阵/`.glass` 玻璃卡/`.amb-title` 渐变标题/`ambRise` 进场关键帧），Screen1 / TraceScreen1 / TraceScreen2 三屏根节点改"全幅氛围层 + 居中内容列"同构，各屏卡片玻璃化；Screen0 首页保持本节私有实现不动（已验收）。工具屏光晕浓度比首页略收敛（工作区属性）。

### 适配与纪律

- **深浅主题**：光晕浓度/边框亮度走 CSS 变量（`.v-theme--dark .wrap` 整组加深），标题渐变换浅色系保对比
- **reduced-motion**：光晕漂移/流光/进场/过渡全量禁用
- **老 Chromium 兼容**：不用 mask-composite / dvh / scroll-driven；mask-image、background-clip 带 -webkit- 前缀（**前缀与标准属性名不同，不属"同名双声明压缩合并"踩坑对象**）
- 仍然有效的红线：**纯入口零数据请求**、单 accent 锁品牌蓝系（光晕副色 rgba(79,144,201) 同族）、系统字体栈、整卡可点键盘可达、MDI 不用 emoji

## 首页红线（原 2026-10-10 版本，装饰类两条已被上节推翻，存档备查）

- 纯入口，**不加载任何项目数据**——最近项目留在工具一第一屏（那里已有），首页保持零请求秒开
- 无 hero、无 eyebrow 小标签、无装饰渐变横幅、无版本脚注装饰
- 单 accent 锁定品牌蓝 #2D5B91，不引入第二强调色
- 字体保持系统栈（离线约束，不引 Google Fonts）

- 「‹ 工具集」返回时**不弹确认**——工具一状态全程保留，返回无代价

## 动效规范

- 屏切换沿用 180ms fade-slide（含 `:duration` 显式定界与 reduced-motion 降级）
- 首页卡片进场：轻微 stagger（150ms 间隔，仅 opacity + translateY），`prefers-reduced-motion` 时直接呈现
- 卡片 hover 升起与现有 v-card 语言一致（150ms）

## 技术实现要点

- `store` 新增 `tool` 字段（`'convert' | 'trace'`）+ `screen = 0` 表首页；`App.vue` 按 `screen === 0` 渲染新组件 `Screen0.vue`（首页），否则按 `store.tool` 渲染对应工具屏
- 现有 `stepClick` 守卫逻辑不变，仅挂到工具一；工具二 stepper 同构实现
- 顶栏标题随态切换（首页 = 工具集名；工具内 = 工具名），复用现有渐变品牌样式
- 打包元数据（exe `--windows-title` 等）随下版发版一并更新为"测试文档工具集"

## 被否决方案（避免重复讨论）

| 方案 | 否决理由 |
|------|----------|
| 首页放"最近项目"聚合区（工作台式） | 首页变重、多一次数据请求；最近项目属于工具一内部第一屏职责 |
| 营销式 hero 大标题 | 内部工具无转化目标，浪费首屏 |
| 三等分/多列栅格预留"未来工具位" | 空卡位是 AI 模板感重灾区；只有 2 个工具就 2 张卡，加工具时再加卡 |
| 侧边栏常驻导航（应用壳） | 两工具规模用不上；顶栏返回足够，且不动现有屏结构 |

## 视觉系统 v2「蓝调鎏光 · 工程仪器」（2026-10-22，v1.6.0）

用户要求"全面样式、动效重新设计和规划，功能不变"，并以 OpenDesign 产出的单文件设计稿（项目 `ccnewtools-visual-system`）为方向。设计稿保存在 OpenDesign 工作区，落地实现见 `web/src/design.css`（令牌 + Vuetify 覆盖）与各屏 scoped 样式。

### 设计令牌（浅 / 深两套独立语义）

- 背景 `#EDF3F9` / `#07111D`；表面 `#FFFFFF` / `#0E1D2F`；浅面 `#F5F8FC` / `#12253A`
- 文字 `#12233B` / `#E9F1FA`；次文字 `#5A6D84` / `#9CAFC5`；弱文字 `#7C8DA2` / `#7F94AC`
- 主色 `#1267B4` / `#67B7FF`；描边 `#D3DFEB` / `#213A54`；强描边 `#B8C9DA` / `#34516F`
- 语义色：成功 `#18794E` / `#68D6A1`；警告 `#986000` / `#FFD277`；危险 `#A83B34` / `#FF938B`
- 圆角阶梯 3/6/10/14/20px；间距 4~64px；阴影三级（蓝调低对比，深色改黑调）
- 动效令牌 120/180/240/320/600ms + `ease-out(.16,1,.3,1)` / `standard(.2,0,0,1)` / `spring`

### 原则与组件规则

- **装饰退到边缘，数据获得实色承载**：光晕与点阵只在页面背景；表格、输入框、面板一律实色表面 + 稳定边框，不使用玻璃/柔光罩
- 按钮 38px 高、6px 圆角、hover 上浮 1px、按压下沉 + 0.985 缩放；输入框浅实底 + 聚焦强调环（3px 主色光晕）
- 必填缺失 = 危险色底 + 描边 + 行内"必填"提示（取代旧的琥珀荧光，语义更明确）
- 步骤表：序号列主色等宽字，行 hover 实色，可疑行危险色底 + 3px 内侧标条
- 树：行高 30px，当前项主色浅底，缩进 14px/层（修旧版双重缩进）
- 告警/Toast/弹层沿用 Vuetify 语义组件，仅统一圆角、边框与阴影

### 六屏布局变化

1. **首页**：左对齐 kicker + 渐变墨水标题；两张实色工具卡（图标块 + 01/02 序号 + 竖向步骤 + 进入行），光标聚光仅作卡片内极轻径向光；页脚离线状态点 + 版本

### 动效清单（全部仅 transform / opacity）

## 视觉系统 v3「蓝图纸面 · 校对台」（2026-10-22，v1.6.0 最终发版方向）

v2 实装后，用户要求"使用 OpenDesign 继续设计重置"。第二轮 OpenDesign 产出了独立重置稿（`ccnewtools-blueprint-reset.html`），以**冷白工程纸 + 蓝黑规线 + 等宽编号**为核心，取消渐变标题、大面积光晕与玻璃堆叠——最终按此方向发版。

### 视觉主张

- **工程纸底**：全站固定 28px 网格（1px 规线，蓝调低透明度），像一张正在校对的工程底图；取消所有光晕/点阵/扫光。
- **纸面承载数据**：所有面板/表格/输入框为纸面实色 + 1px 强规线（`--cn-border-strong`），圆角统一 2px；阴影仅用于浮层（菜单/对话框/Toast）。
- **排版**：标题用 Bahnschrift SemiCondensed（Windows 系统字体，回退雅黑）大字距紧排；编号/标识/统计值一律等宽；栏目标签为小号等宽大写。
- **色彩**：交互色仅工程蓝 `#075DA8`（深色 `#51B5FF`）；告警只用琥珀 `#9B6100`；成功 `#176B4A`；危险 `#A33B35`。深色主题为"图纸反相"（`#06131D` 底 / `#0B1D2A` 纸面）。
- **组件**：按钮 36px/2px 直角；输入框纸面 + 1px 强规线，聚焦蓝色描边 + 2px 浅蓝环；树使用左侧连接线；步骤表为印刷表格（四边规线、序号列蓝色等宽）；数据表表头用墨色底反白（双层 sticky）。
