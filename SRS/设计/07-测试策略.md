# 07 测试策略

> 状态：**已定稿**（2026-09-30，与第 7 节打包交付同日过定）

## 一、总体思路

三层架构输入输出都是纯数据（[01-整体架构](01-整体架构.md)），天然可分层测试。涉密大纲**不进仓库**，所以测试数据分两路：

- **仓库内**：自制脱敏最小样本（合成 .docx fixture），每条解析规则至少一个样本；
- **本地真实数据**：验收脚本读 `文档S/` 下的真实大纲，只输出统计数字，数据与脚本分离。

**硬性验收（用户 2026-09-30 明确）**：**大纲的不同写法（变种）都必须转换成功**。对应测试 `tests/m1-variants.test.ts`——一份合成大纲同时包含全部已知变种（level-4 挂表、三级正常、跳级、缺分隔符标题、悬空小标题、列表吸收、准则格配对、描述子项不一致等），断言**零错误**；今后每发现新变种，先加 fixture 再修规则。

## 二、分层测试

### 1. 解析层 —— 单测 + 黄金统计回归（重点）

**单测**（fixture 驱动，规则数 ≈ 用例数）：覆盖 [02-解析层](02-解析层.md) 的每一条规则——章节号还原、标题三种挂载层级 + 跳级、表格识别、段落两形态、用例切分、步骤切分、引导句、悬空小标题丢弃、共用综述、描述与方法子项不一致、标识不一致兜底、列表段落剔除编号。

**黄金统计回归**：对本地真实大纲跑解析，产出统计 JSON 与基线比对。改动任何解析规则后必须先跑这个（`bun scripts/acceptance.ts <大纲> --expect 37:110:528`）：

| 基线 | 测试项 | 用例 | 步骤 |
|------|--------|------|------|
| A星大纲 V1.10 | 37 | 110 | 528 |
| BCD变种大纲 | 37 | 110 | 528 |

> 基线于 2026-09-30 实现后测定（M1），替代早期原型不可复现的 112/544 口径，更正说明见 [02-解析层 第七节](02-解析层.md)。两份结构不同的大纲结果完全一致，交叉印证。

统计同时输出**问题清单计数**（错误/告警/提示条数），规则改动导致数字漂移时逐条核对原因，不允许"数字变了但说不清为什么"。

### 2. 转换层 —— 纯函数单测

用例标识生成（[03 第二节](03-转换层.md) 的推导表直接做成用例：`XQ_SU_ZLPA→YL_SU_ZLPA_001`、`XQ_DC→YL_DC_001`，序号每项重新从 001 起）、步骤切分关键词规则、可疑判定启发式（[03 第五节](03-转换层.md)）、排序规则、默认值填充。无 IO，全部秒级跑完。

### 3. 渲染层 —— 结构断言 + 人工比对

- **结构断言**（自动）：用固定模板数据渲染，解析产物 docx 断言表格行数 = 用例数、关键变量文本存在、说明与记录两份都完整。不断言字节（docx 含时间戳，二进制不稳定）。
- **人工比对**：文档S 里有老工具产出的测试说明/记录样例，生成结果与样例**逐栏目比对**（表格结构、追踪关系、序号、字体版式），出比对清单，发版前过一遍。

### 4. 前端 / 交互 —— 手工冒烟清单

按三屏主路径 + [06-错误处理](06-错误处理.md) 的错误注入场景列清单：非 docx、损坏文件、加密文档、被 Word 占用、无用例标题、零步骤、切分可疑、缺人员参数拦截、编辑持久化（关浏览器重开恢复）、大纲更新后编辑匹配恢复。

### 5. 端到端

脱敏样本大纲走完整流程（导入 → 核对 → 生成），产物能在 Word 与 WPS 中正常打开（人工确认版式）。

## 三、跨平台测试矩阵

| 平台 | 级别 | 内容 |
|------|------|------|
| Windows 11（开发机） | 全量 | 单测 + 黄金统计 + 端到端 + 冒烟 |
| Windows 10（老机器） | 冒烟 | 启动、完整生成一份、浏览器兼容 |
| **银河麒麟 V10 x64（实机）** | **验收必做** | 启动、完整生成一份、**系统自带浏览器**下三屏全流程（Vuetify 3 对老内核浏览器的兼容性是重点观察项） |
| Linux ARM64（飞腾/鲲鹏） | 有机器则测 | 同麒麟；无机器则交付物标注"未实机验证" |

> Bun 交叉编译产物在麒麟 V10 的兼容性此前只有"编译成功"的证据，**实机运行验收是最后一道关**，若失败立即记 [踩坑](../踩坑/踩坑记录.md) 并评估替代方案。

## 四、性能验收（对应[非功能需求](../需求/03-非功能需求.md)）

- 解析 463 段落 / 68 表的大纲：< **1 秒**（黄金统计脚本顺带计时）
- 渲染两份文档：< **3 秒**
- 最大测试项（遥控指令模版管理，16 用例）在核对屏切换无卡顿

## 五、发版前验收清单

1. 单测全绿
2. 黄金统计与基线一致（漂移逐条解释）
3. 人工比对清单过完（对照老工具样例）
4. 性能达标
5. 断网环境完整走通一遍（离线硬性要求）
6. 麒麟 V10 实机验收通过
7. 错误注入冒烟清单过完
