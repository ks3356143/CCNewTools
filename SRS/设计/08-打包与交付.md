# 08 打包与交付

> 状态：**已定稿**（2026-09-30，与第 6 节测试策略同日过定）

## 一、构建流程

```
bun install
   ↓
bun run build            前端产物（Vue3 + Vuetify + 图标字体，全部本地化）
   ↓
bun scripts/打包.ts       assets.ts 资产清单生成 + 三目标单文件编译
   ↓
产物：dist/发布/CCNewTools_v<版本>_<平台>.<ext>
```

| 平台 | 产物 |
|------|------|
| Windows x64 | `CCNewTools_v<版本>_win-x64.exe` |
| Linux x64 | `CCNewTools_v<版本>_linux-x64` |
| 麒麟 V10 | `CCNewTools_v<版本>_kylin-v10`（与 linux-x64 同二进制复制命名，glibc 2.31 ≥ Bun 2.28 门槛） |

> 产物文件名前缀 **CCNewTools（ASCII）**：GitHub Release 会剥离附件名中的非 ASCII 字符（踩坑 2026-10-03），早期中文名 `测试文档生成工具_v…` 上传后只剩 `_v…`（v1.0.0~v1.0.1 均如此）；v1.1.0 起从源头改 ASCII 前缀。产物内部（exe 标题、启动横幅、界面）仍是"测试文档生成工具"。

**嵌入机制（2026-10-01 实现定稿）**：打包脚本扫描 web/dist 生成 `src/server/assets.ts`（逐文件 `import with {type:'file'}`），app.ts/api.ts 运行时先查嵌入映射、查不到走磁盘——开发形态与单文件形态共用同一套服务代码，**开发时 assets.ts 是空映射**（提交库的即此形态）。Windows 编译附 `--windows-icon=资源/app.ico`（多尺寸 ICO，按 favicon 设计用 Pillow 生成，生成脚本思路见踩坑记录）与版本资源（title/version/publisher/description）。已实测：干净目录双击 exe → v1.0.0、HTML/JS/字体/图标全部内嵌命中、无 模板/ 目录时生成文档走嵌入模板成功。

**内嵌资源**（全部打进二进制，不外置）：前端产物、`测试说明模板.docx`、`测试记录模板.docx`、Material Design Icons 字体、版本信息。模板要改就得重新打包——这是单文件形态的已知取舍，换取拷贝即用。

## 二、版本号

语义化 `v主.次.修订`：

- **主**：输出文档格式/业务规则不兼容的变更
- **次**：解析规则、功能新增
- **修订**：缺陷修复、界面微调

版本号三处可见：启动控制台横幅、界面"关于"、编辑记录 JSON（便于排查历史数据是哪版产生的）。

## 三、运行时行为

1. 双击 → 起本地 HTTP 服务，**只监听 127.0.0.1**
2. 端口默认固定，被占则自动顺延并提示实际地址
3. 双击启动**自动打开默认浏览器**（v1.1.4 起；v1.0.0~v1.1.3 需 `--open` 参数才打开，01 架构文档写的启动流程直到此时才落地）。`--no-open` 参数禁用自动打开（自动化/脚本/冒烟场景）。无桌面或无默认浏览器环境静默跳过（spawn 失败必须吞掉，否则会被端口重试误判），控制台显示的 `http://127.0.0.1:<端口>` 供手动访问兜底
4. 关闭 = 关闭控制台窗口（服务随之结束；编辑已持久化，不丢数据）
5. 控制台中文（Windows，v1.1.3）：启动即把控制台输出代码页切到 UTF-8（kernel32 SetConsoleOutputCP 经 Bun FFI，失败静默——地址行是 ASCII，乱码不影响使用）
6. 运行位置风险提示（v1.1.3）：exe 位于临时目录（压缩包里直接双击的典型形态）或网络共享（UNC 路径）时横幅警示——前者数据随临时目录被清，后者多人共用互相覆盖
7. 老浏览器白屏兜底（v1.1.3）：index.html 的 #app 内置加载提示，bundle 无法执行时页面留下"浏览器过旧请换新版"线索；正常加载时被 Vue mount 整体替换

数据目录（与 [05-界面设计](05-界面设计.md) 持久化方案一致）：

```
<exe目录>/
├── 测试文档生成工具.exe
└── 数据/
    ├── 项目/       每份大纲一个项目目录（项目.json + 大纲.docx 源副本）
    │   └── <hash12>/…
    ├── 设置.json   全局参数与主题
    └── 日志/       滚动保留最近 5 个
```

`数据/` 不可写时整体回退到 `%USERPROFILE%/CCNewTools/` 并提示一次（提示 v1.1.2 起随启动横幅打印，此前是静默回退的 Bug）。

**锚定规则（2026-10-07 v1.1.2 修正）**：数据目录锚定 **exe 所在目录**——编译形态经 `process.execPath` 判定（编译态指向 exe 自身且与启动时 cwd 无关，2026-10-07 探测实证；开发态指向 bun 运行时，沿用工作目录）。v1.1.1 及之前按 cwd 锚定，右键"以管理员身份运行"（cwd=System32）、快捷方式改过"起始位置"、终端他处启动都会让涉密数据散落到工作目录甚至用户目录。`CC_DATA_DIR` 环境变量可强制指定（排障用，不对外宣传）。启动横幅显示数据目录实际位置，便于用户查找与迁移。

## 五、升级与回滚

- **升级 = 覆盖 exe**，`数据/` 目录不动；项目存档带版本号，新版本读到旧语义存档时整体作废（按新规则重新转换）；启动时自动把旧版 `编辑记录/` 迁入 `项目/`（见 [09-本地数据管理](09-本地数据管理.md)），迁移失败不炸主流程
- **回滚 = 换回旧 exe**；保留上一版 exe 于 `数据/旧版本/` 下由用户自行决定是否留存
- 模板变更随版本走，旧版生成的文档不受影响

## 六、已知风险与对策

| 风险 | 对策 |
|------|------|
| **Bun 产物在麒麟 V10 实机不兼容**（此前仅有编译成功证据） | [07-测试策略](07-测试策略.md) 的实机验收为最后一道关；若失败，回退方案是 Debian 11 容器内低 glibc 环境构建（参考踩坑记录 PyInstaller 条目）或改用 Node 单文件方案 |
| 杀毒软件误报单文件 exe | 交付说明写明处理方式（加入白名单）；先在内网一台机器试用确认 |
| 麒麟自带浏览器内核过老渲染异常 | 验收清单观察项；必要时为前端降级 CSS 特性（实现期控制） |
