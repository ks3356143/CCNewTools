# 05 界面设计

> 状态：**待与用户讨论**（尚未开始讨论）
> 用户明确要求：**界面要好看**，组件库已点名 **Vuetify**

## 技术选型

- **Vue 3 + Vuetify 3**（Material Design 3 主题）
- 由 Bun 打包前端，产物内嵌进可执行文件
- **所有资源本地化**：Material Design Icons 字体（约 400KB）打包进去；中文字体用系统回退（不打包，省十几 MB）
- 无任何外链，内网可用

## 三屏流程（初步设想，未确认）

### 第 1 屏：选择大纲

```
┌──────────────────────────────────────────────┐
│  测试文档生成工具                              │
├──────────────────────────────────────────────┤
│                                              │
│        ┌────────────────────────┐            │
│        │   ⬆  拖入或点击选择      │            │
│        │      测试大纲 .docx     │            │
│        └────────────────────────┘            │
│                                              │
│   解析完成后显示概要：                         │
│   ✔ 识别到 37 个测试项、112 个测试用例、        │
│     544 个测试步骤                            │
│   ⚠ 1 条告警：XQ_SU_ZLQQ 与 XQ_SU_ZLQX_SU01   │
│     不一致，已以用例标题中的标识为准            │
└──────────────────────────────────────────────┘
```

### 第 2 屏：核对与编辑（**核心屏**）

```
┌────────────┬─────────────────────────────────────────┐
│ 测试类型    │  全局参数（可编辑、有记忆）                │
│ ├ 文档审查  │  用例初始化 [外接设备或软件运行正常    ]  │
│ ├ 功能测试  │  前提和约束 [软件正常工作，环境连接正常]  │
│ │ ├ 参数管理│  设计人员   [陈俊亦]                     │
│ │ │ ├用例1 │  测试时间   [2026-09-29]               │
│ │ │ ├用例2 │  测试人员   [      ]  监测人员 [      ] │
│ │ │ └用例3 │  ─────────────────────────────────────  │
│ │ └ 指令生成│  当前用例：参数查询正常功能               │
│ └ 性能测试  │  标识 YL_SU_ZLPA_001                    │
│            │  需求标识 XQ_SU_ZLPA_SU01                │
│            │  ─────────────────────────────────────  │
│            │  序号 │ 输入及操作      │ 期望结果与评估  │
│            │   1   │ 在参数列表下方… │ 查看查询结果…  │
│            │   2   │ 使用top命令     │ 查看软件空闲…⚠ │
│            │       │                │  [双击可改]    │
│            │  ─────────────────────────────────────  │
│            │              [ 生成文档 ]               │
└────────────┴─────────────────────────────────────────┘
```

**要点**：

- 左侧树形导航：测试类型 → 测试项 → 用例
- 步骤表格**可直接编辑**（双击单元格）
- **切分可疑的条目高亮**（如 ⚠），让用户快速定位需要人工看的地方
- 全局参数改动对所有用例生效
