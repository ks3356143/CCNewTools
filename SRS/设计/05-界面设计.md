## 编辑持久化方案（已确认，存本地 JSON + 影响域隔离）

**核心原则：每份大纲一份记录，互不干扰；所有数据只落在本工具自己的文件夹。**

- **存储位置**：可执行文件同目录的 `数据/编辑记录/` 文件夹（便携式，跟着 exe 走）；该目录不可写时回退到 `%USERPROFILE%/CCNewTools/编辑记录/`。不写注册表，不碰其他项目和其他工具的任何目录
- **文件命名**：`<大纲文件名>_<大纲内容哈希前8位>.json`（如 `XX星测试大纲V1.10_3fa2b1c8.json`）——文件名 + 内容双重区分，A 大纲的编辑绝不会串到 B 大纲；不同卫星项目、不同版本的大纲各自独立
- **JSON 内容**：大纲文件名与哈希、保存时间、全局参数（人员/初始化/约束等）、每个用例的步骤文本修改、可疑步"确认无误"记录、已核对状态
- **自动保存**：编辑后防抖约 1 秒自动写盘，无需手动保存
- **恢复与校验**：导入大纲解析完成后自动查找对应记录并恢复；若大纲哈希对不上（大纲改过），则按用例标识 + 步骤文本匹配，能对上的恢复、对不上的丢弃，并提示"大纲已更新，恢复了 n 处编辑、m 处无法对应已忽略"

## v5 精修（2026-10-22，OpenDesign 评审落地）

第三轮视觉（「冷蓝晨雾 · 精密仪器」v4）已发版 v1.7.x 后，用 OpenDesign 做了一次**组件级精修评审**（18 条 P0/P1），落地要点如下，后续改动以本节数值为准：

- **节奏**：页面左右 24px；核对屏状态带 min-height 76px（12px 上下内边距）；编辑区 16px 24px；参数栏 14px 16px 20px；底部操作栏 64px
- **三栏（已被 v5.1 取代）**：`288px minmax(0,1fr) 312px`（中央用例表为主工作区；<1180px 单列堆叠，顺序为 目录 → 编辑区 → 参数区，目录限高 340px 可滚）
- **字阶**：页题 22/1.3/650（保留 kicker + 元信息，未取 24px）；用例标题 17/1.4/650；正文 13/1.55；辅助 11.5~12；仅元信息 10~11
- **数字**：全局 `font-variant-numeric: tabular-nums`（步骤号/进度/计数不跳列）
- **步骤表**：表头 38px `#F4F9FE/#4C617B/650`，数据行 42px（可被两行内容撑高），格内 10px 12px；列宽 `48px / 42% / auto / 156px`；行线 `--cn-row-line(#E7EFF8)`；hover `#F3F8FF`；**去掉斑马纹**（与 hover/可疑底竞争）
- **目录树**：行高 34px，缩进 16px/层（保住 288px 宽度），选中 `#E9F3FF + #1459A9` + 左侧 3px 内阴影主色条；展开 200ms 淡入上移
- **追踪预览**：双层表头第一行 `#F4F9FE`、第二行 `#173B62` 反白（产品蓝锚定），行高 38/34；合并边界 `#C9D9EA`
- **状态胶囊**：26px 高、12/18/600；可疑 `#FFF4F5/#D55463`、告警 `#FFF8E9/#C58A22`、正常 `#E6F7F1/#1F9975`
- **按钮**：常规 40px/9px；small 32px；tonal = 白底 + 1px 描边（次级），text = 透明；主按钮仅 CTA 用蓝色纵向渐变；图标按钮默认透明无描边，hover 才上浅蓝；禁用态实心按钮用 `surface-soft` 底 + `subtle` 字，图标按钮只降透明度
- **必填错误**：只保留 1px `#D55463` + `#FFF9FA` 浅底 + 10.5/16 `#B63D4D` 行内提示；标签保持常规色，仅 `*` 为红；占位文案改"请输入"
- **焦点/禁用**：`:focus-visible` 统一 3px `rgba(47,128,232,.22)` 外环；**输入类元素除外**（字段自带整圈描边，否则搜索框图标后会出现一条方环竖线）
- **深色**：背景 `#0D1826` / 表面 `#122238` / 浅面 `#172A43` / 描边 `#28405C` / 玻璃 `rgba(15,31,50,.82)`；语义色主 `#65A9F4`、成功 `#45C29B`、警告 `#E0AF5A`、危险 `#F07886`，语义浅底降饱和（`#14352F/#2E2A1D/#33232A`）
- **动效**：入场令牌 420ms（现有屏保持 320ms 更利落）、状态带/面板 transition 120~180ms、树 200ms；只动 transform/opacity，reduced-motion 全量降级
- **老内核兜底**：`.v-application` 先写 `min-height:100vh` 再写 `100dvh`（Chrome/Edge 100 不认 dvh）
- **刷新恢复与空态（v1.7.3）**：用 sessionStorage 记最近会话（视图 / 屏号 / 大纲 hash / 当前用例），同标签刷新时静默重开项目并回到核对屏与原用例；新开标签没有会话，自然回首页；显式深链（?view=…）不抢屏；工具二刷新回选择页（追踪规格只在内存）。选大纲无最近项目时，右侧显示虚线空态框（图标 + 说明），不再留白。全局 `html/body` 禁横向滚动，避免装饰层或长文本把页面顶歪。

## v5.2 动效与组件性能（2026-10-23）

- **屏切换**：180ms fade + translateY(8→0 / -4)，`:duration` 与 CSS 时长一致（此前 240/180 不一致会截断入场）
- **全局参数抽屉**：240ms，`cubic-bezier(.2,.75,.25,1)`；关闭态不挂载表单（8 个输入框），打开时再建
- **目录树**：展开 200ms 淡入上移；行高 28px；每行可疑点拆为 `SuspectDot`，切用例时不重算整层步骤
- **按钮 / 行**：按钮 180ms，树行 hover 120ms，进度条 320ms，红色荧光 2.4s 呼吸（`prefers-reduced-motion` 下关闭）
- **性能基线**：300 用例同层（1449 DOM 节点），连续切 20 次用例 **0 个长任务**，约 4ms/次
- 除荧光用 box-shadow 外，动效只改 transform/opacity；reduced-motion 覆盖屏切换、抽屉、树展开、荧光
