# 实施计划

> 状态：**已产出**（2026-09-30）。设计依据：[01~08 设计文档](../目录.md)，测试依据：[07-测试策略](../设计/07-测试策略.md)
> 约定：**每个里程碑完成 = 单测全绿 + git 提交 + 更新[当前进度](../进度/当前进度.md)**；涉密数据永不进仓库；遇坑立即记[踩坑](../踩坑/踩坑记录.md)。

## 一、工程结构

```
CCNewTools/
├── src/
│   ├── server/            # 服务层（Bun HTTP）
│   │   ├── index.ts       # 入口：起服务、托管前端产物、自动开浏览器
│   │   ├── api.ts         # /api/* 路由
│   │   └── log.ts         # 数据/日志 滚动日志
│   ├── core/              # 三层纯逻辑（无网络/界面依赖，可独立测试）
│   │   ├── parse/         # 解析层：docx.ts / numbering.ts / outline.ts / table.ts / cases.ts
│   │   ├── convert/       # 转换层：caseId.ts / split.ts / index.ts
│   │   ├── render/        # 渲染层：docx.ts
│   │   └── issues.ts      # 三级问题收集（错误/告警/提示）
│   ├── domain.ts          # 领域模型类型（测试类型→测试项→用例→步骤 + 问题清单）
│   └── persistence.ts     # 编辑记录 JSON（哈希命名、恢复匹配、目录回退）
├── web/                   # Vue 3 + Vuetify 前端（vite 构建，产物内嵌）
├── tests/                 # bun test：parse / convert / render / api
│   └── fixtures/          # 合成脱敏样本（由脚本生成，入库）
├── scripts/
│   ├── make-fixtures.ts   # 纯代码拼 OOXML 生成合成 .docx（不依赖 Word）
│   └── acceptance.ts      # 黄金统计验收 CLI（读本地真实大纲，只出统计数字）
├── 模板/                  # 已有：测试说明模板.docx / 测试记录模板.docx
└── package.json           # bun run dev / test / build / acceptance
```

**依赖**：docxtemplater + pizzip（渲染）、@xmldom/xmldom（XML 解析，docxtemplater 已带）、fflate（zip）、vue + vuetify + vite（前端）。全部走 npmmirror 镜像。

## 二、里程碑

### M0 工程骨架（约半天）

| # | 任务 | 产出 |
|---|------|------|
| 0.1 | 初始化 Bun 工程，装依赖（配 npmmirror） | package.json 可 `bun install` |
| 0.2 | Bun HTTP 服务：托管静态目录 + `/api/ping`；默认端口 8300，被占顺延 | src/server/index.ts |
| 0.3 | Vite + Vue3 + Vuetify 骨架，构建产物由服务托管；dev 模式代理 /api | web/ 可跑 |

**判据**：`bun run dev` 起服务、浏览器看到 Vuetify 空壳页；`bun test` 绿；`ping` 通。

### M1 解析层（2~3 天，本项目的地基）

| # | 任务 | 对应规则 |
|---|------|---------|
| 1.1 | domain.ts 类型 + issues.ts 三级问题收集 | [06](../设计/06-错误处理.md) |
| 1.2 | docx.ts：fflate 解 zip，读 document.xml / numbering.xml（只读打开） | 踩坑：Word 占用 |
| 1.3 | numbering.ts：numId→abstractNum 映射 + ilvl 计数器还原章节号 | [02 第二节](../设计/02-解析层.md) |
| 1.4 | outline.ts：定位"测试项及方法"节（下一级 ≤2 标题终止）；标题路径（4/5/6 级混挂 + 跳级） | 02 第二节 |
| 1.5 | table.ts：识别"测试项名称"表，按行标签取 7 行字段；单元格段落提取（普通段 + 列表段保序、剔除自动编号标记） | 02 第三、四、五节 |
| 1.6 | cases.ts：用例标题切分、引导句、步骤切分、悬空小标题丢弃、综述匹配（含共用回退）、标识不一致兜底 | 02 第六、八、九节 |
| 1.7 | make-fixtures.ts：为上述每条规则造合成样本（每条至少 1 个） | [07 测试策略](../设计/07-测试策略.md) |
| 1.8 | acceptance.ts 黄金统计 CLI + 基线比对 | 07 基线表 |

**判据**：单测全绿；A星大纲 **37/112/544** 命中基线、BCD 变种 **37/109** 命中（步骤数测定后回填 07 文档）；解析耗时 < 1s；**把 acceptance.ts 交叉编译成 linux-x64 CLI，交用户在麒麟 V10 实机试跑——最早暴露 Bun 兼容性风险（M6 大风险的前置排雷）**。

### M4 服务层 + 持久化（1 天）

| # | 任务 | 说明 |

### M5 前端实装（2~3 天，按原型复刻 + 定稿增量）

三屏照 [原型](../../原型/界面原型.html) 实现，另加已定稿的增量：

- 第 1 屏：三级问题清单**可点击跳转**对应用例；导入失败的终止性错误文案（06 表格）
- 第 2 屏：步骤行**新增/删除/上移/下移**、"不生成此用例"、树上错误红点、用例面板问题条、编辑防抖自动保存、全局参数记忆
- 第 3 屏：进度条 + 逐表日志（生成 API 返回每张表的处理记录，前端回放展示，真实表名）
- 主题：默认浅色、可切深色并记忆

**判据**：[06](../设计/06-错误处理.md) 错误注入冒烟清单全过；观感与原型一致（对照原型逐屏检查）。
