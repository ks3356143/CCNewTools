# 整体需求概述

> 状态：**已确认**（2026-09-29）。以下内容基于与用户的实际沟通确定。

## 项目定位

CCNewTools：**测试文档工具集**（离线、跨平台、单文件）。现有两个工具：

- **工具一 · 大纲转换**：从第三方测试大纲（.docx）解析测试项表格，自动生成**测试说明**和**测试记录**两份 Word 文档（本项目起点，替代老项目 `newToolforTest`）
- **工具二 · 追踪文档生成**：从测试大纲生成"大纲 ↔ 需求规格说明"追踪关系文档，用户复制其中表格贴入自有文档

入口为**工具集首页**（工具卡片选择），设计见 [设计/11-工具集首页](../设计/11-工具集首页.md)。

## 要解决的问题

老项目 [`newToolforTest`](https://github.com/ks3356143/newToolforTest) 实现了同样的功能，但：

1. **只能在 Windows 跑**——用 PyQt5 + `win32com` 直接驱动 Microsoft Word
2. **需要装 Office**——目标机器上必须有 Word
3. **界面老旧**——PyQt5 默认样式

本工具要在**不依赖 Office、不依赖 Windows** 的前提下重做一遍，并且界面要好看。

## 使用场景

- 使用者：第三方测试机构的测试工程师
- 运行环境：**内网 / 无网络环境**（涉密），可能部署在**银河麒麟 V10** 等国产化系统上
- 使用方式：**发给同事，双击即用**，对方机器上不需要装任何东西

## 项目目标

1. 选择一个测试大纲文档，自动解析出测试项、测试用例、测试步骤
2. 生成符合模板的测试说明和测试记录 Word 文档
3. **完全离线**运行，无任何网络请求
4. **跨平台**：Windows / Linux x64 / Linux ARM64
5. **单文件分发**，零安装
6. 界面美观（用户明确要求）

## 范围

### 包含

- 工具集首页（多工具入口）
- 工具一：解析测试大纲的"测试项及方法"章节；提取测试项表格中的字段、切分用例与步骤；按模板生成测试说明与测试记录；界面核对、修正解析结果和填写全局参数
- 工具二：从测试大纲生成追踪关系文档（现追踪表独立成档，见 [设计/12-追踪文档工具](../设计/12-追踪文档工具.md)）

### 不包含

- 不解析大纲的其他章节（测试依据、环境、组织、附录等）
- 不生成测试大纲本身
- 不做测试执行管理、缺陷跟踪
- 不依赖 OfficeCLI / Microsoft Word / 任何在线服务

## 与老项目的关系

| | 老项目 newToolforTest | 本项目 |
|---|---|---|
| 界面 | PyQt5 桌面窗口 | 浏览器（Vue 3 + Vuetify） |
| Word 处理 | win32com（需装 Office） | 自研 OOXML 解析 + docxtemplater |
| 平台 | 仅 Windows | Windows / Linux x64 / Linux ARM64 |
| 分发 | 需要 Python + Office 环境 | 单个可执行文件 |
| 解析逻辑 | 靠冒号、括号、分号做文本切分 | 按段落结构 + 标点语义切分 |

**老项目仍有参考价值**：字段映射规则、默认值、用例标识生成规则都沿用了老项目的约定（见 [03-转换层](../设计/03-转换层.md)）。
