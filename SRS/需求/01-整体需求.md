# 整体需求概述

> 状态：初始版。项目刚启动，以下内容基于 README 与当前沟通整理，待逐步细化。

## 项目定位

CCNewTools：**CPU 测评数据的转换工具**，目标是**任意平台使用**（跨平台）。

## 要解决的问题

CPU 测评数据分散在不同来源（测评网站、厂商规格表等），格式各异，难以直接对比与分析。本工具用于将这些数据转换/归一化，便于使用。（具体场景待与用户确认）

## 项目目标

1. （待定）支持主流 CPU 测评数据源的导入
2. （待定）转换为目标格式输出
3. （待定）跨平台运行：Windows / macOS / Linux
