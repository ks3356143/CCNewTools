# 非功能需求

> 状态：**已确认**（2026-09-29）

## 1. 离线运行（**硬性**）

**必须在完全无网络的环境下运行。** 用户明确强调。

具体要求：

| 排除项 | 原因 |
|--------|------|
| 前端 CDN 引 CSS/JS/字体 | 内网加载不出来 |
| 在线授权校验、云 API | 连不上 |
| 运行时下载任何资源 | 内网下载失败 |
| 让用户自己 `pip install` / `npm install` | 内网装不了 |
| 依赖系统已装的 Office | 内网机器未必有 |

交付物必须**自包含**：拷进去就能跑。

> **踩过的坑**：Flet 的 `flet-desktop` 包只有 14KB，首次运行时联网从 GitHub 下载 Flutter 客户端——无网环境直接失败。同类坑在 NiceGUI（需要 WebView2）上也踩过。选型时已排除。

## 2. 平台兼容性（**硬性**）

必须跨平台，且**必须覆盖银河麒麟 V10**（国产化要求）。

| 平台 | 支持 | 说明 |
|------|------|------|
| Windows x64 | ✅ | 开发机即可编译 |
| Linux x64 | ✅ | Windows 上交叉编译，实测成功 |
| Linux ARM64（飞腾/鲲鹏） | ✅ | Windows 上交叉编译，实测成功 |
| 银河麒麟 V10 | ✅ | 编译型单文件，**不受 glibc 版本限制** |
| macOS | 未验证 | Bun 支持，无目标需求 |

> **踩过的坑**：麒麟 V10 的 glibc 是 2.31，而 PySide6 6.10+ 要求 2.34、ARM64 轮子要求 2.39，直接导致整个 Qt 方案被否决。编译型语言没有这个问题。

## 3. 分发方式（**硬性**）

- **单个可执行文件**，双击即用
- 目标机器上**不需要安装任何运行时**（Python / Node / .NET / Office 都不要）
- 体积：实测 Bun 编译产物约 80MB（Windows 83MB / Linux 79MB），可接受

## 4. 界面

- 用户明确要求**界面好看**，点名 Vuetify
- 中文界面
- 浏览器打开，不依赖 WebView2

## 5. 性能

- 解析一份 463 段落 / 68 张表的大纲应在**毫秒级**完成（自研解析，非 officecli 导出 HTML 的 3.2 秒）
- 渲染两份文档应在**秒级**完成
- 整体交互无卡顿

## 6. 可维护性

- 三层架构（解析 / 转换 / 渲染）职责分离，各层输入输出都是纯数据，可独立测试
- 业务规则集中在转换层，改动不波及解析和渲染
- 所有依赖必须能从国内镜像安装（开发机网络受限）

## 7. 安全

- 服务**只监听 127.0.0.1**，不对外暴露
- 不采集、不上传任何数据
- **真实业务文档（`文档S/`）不得提交进 git**
