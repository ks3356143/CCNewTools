# 踩坑记录

开发/使用过程中遇到的问题与解决方案。问题解决后立即记录，避免重复踩坑。

| 日期 | 环境 | 现象 | 原因 | 解法 |
|------|------|------|------|------|
| 2026-09-29 | Windows 10 + Git Bash | 直连 GitHub HTTPS（curl / PowerShell 下载）失败，SSL 错误或超时 | 网络环境无法直连 GitHub HTTPS | 走本地代理：`curl -x http://127.0.0.1:7890`（代理程序开启时可用）；git 的 SSH 方式不受影响 |
| 2026-09-29 | Windows 10 | 系统无 winget，无法 `winget install gh` | Win10 未预装 App Installer | gh 用 Chocolatey 安装（`choco install gh`）；winget 本身从 GitHub release 下载 msixbundle 后 `Add-AppxPackage` 安装 |
| 2026-09-29 | Windows 10 + Git Bash | 新装 gh 后当前/后台 shell 找不到命令；后台任务中导出 PATH 也可能失效 | shell 的 PATH 是启动时快照；后台任务环境更精简 | 用绝对路径调用（`"/c/Program Files/GitHub CLI/gh.exe"`），或新开终端刷新 PATH |
